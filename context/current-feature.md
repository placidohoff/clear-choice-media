## Goals

## Notes

- The project is a Next.js App Router application using React 19.
- The homepage is defined in app/page.tsx and is the route for the root URL (/).
- Global styling lives in app/globals.css and uses Tailwind utility classes.
- app/layout.tsx wraps the entire app and is the place for site metadata and shared layout structure.
- The landing page foundation is in place, including the premium dark editorial design, navigable sections, mobile menu, and branded favicon.
- This feature is considered partially complete because final polish, content refinement, and any remaining production copy or asset updates are still optional follow-up work.
